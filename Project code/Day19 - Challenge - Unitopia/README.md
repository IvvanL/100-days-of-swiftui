# Unitopia ⏱️

A minimal time unit converter app built with SwiftUI as part of the 100 Days of SwiftUI challenge.

## Features
- Convert seconds into Minutes, Hours, or Days instantly
- Clean, native iOS form-based UI
- Dark mode support
- Built entirely with SwiftUI

## Screenshots
![Unitopia Light Mode](screenshot1.png)
![Unitopia Dark Mode](screenshot2.png)

## How It Works
Enter any number of seconds, pick your target unit, and the result updates instantly.

## Built With
- Swift
- SwiftUI
- Xcode

## What I Learned
- SwiftUI forms and sections
- Computed properties for real-time calculations
- State management with `@State`
- Dark mode with `preferredColorScheme`
- Using dictionaries for clean conversion logic
